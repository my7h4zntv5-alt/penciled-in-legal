# Penciled In — Legal

Static privacy-policy page (`index.html`) packaged as apps:

- **Android**: [Capacitor](https://capacitorjs.com/) wraps the page in a WebView.
- **Windows**: [Electron](https://www.electronjs.org/) + electron-builder.

`index.html` is unchanged and stays at the repo root (so web hosting keeps working). `npm run build:web` copies it to `www/`, which both wrappers consume. The `android/` project is generated by Capacitor and not committed.

## Prerequisites
Node.js 20+. Android: JDK 17 and Android SDK (`ANDROID_HOME` set). Windows build: run on Windows.

## Local Android debug build
```
npm install
npm run android:add     # first time only
npm run android:debug
```
APK: `android/app/build/outputs/apk/debug/app-debug.apk`

## Local Windows build
```
npm install
npm run electron:start  # run in a window
npm run windows:build   # installer + portable exe in dist/
```

## Release builds
- Android: `npm run android:release` produces an AAB at `android/app/build/outputs/bundle/release/`. Sign it with your own keystore (configure signing in `android/app/build.gradle` or use Android Studio's *Generate Signed Bundle*).
- Windows: `npm run windows:build` outputs to `dist/`. Code signing requires a certificate via electron-builder's `CSC_LINK` / `CSC_KEY_PASSWORD` env vars.

## CI
`.github/workflows/android.yml` and `windows.yml` build on push, PR and manual dispatch, and upload the debug APK (`android-debug-apk`) and Windows installers (`windows-installer`) as artifacts.

## Limitations
- Android release artifact is not built/signed in CI (needs a keystore secret).
- Windows build is unsigned (SmartScreen warnings).
- No app icons customised; defaults are used.
- Electron was chosen over Tauri for simpler tooling (no Rust toolchain), at the cost of a larger binary.
